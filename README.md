# Hello World Example

## USB-UART透传与波特率命令

ESP32-S3的USB Serial/JTAG虚拟串口与UART1（TX=GPIO5、RX=GPIO4）双向透传，
UART1上电默认波特率为115200。

在串口助手中发送以下控制命令可动态修改UART1波特率：

```text
--c 9600
--c 921600
```

- 命令可使用`CR`、`LF`或`CRLF`结尾；不发送换行时，会在USB输入空闲50 ms后执行。
- 成功时USB虚拟串口返回`OK: UART baudrate=<数值>`；格式或范围错误会返回`ERROR`。
- 支持范围为300～5000000 baud，修改仅在本次运行期间有效，设备重启后恢复115200。
- 只有位于一段输入开头或换行后的精确`--c`命令会被拦截；其他数据保持原字节透传到UART1。

Starts a FreeRTOS task to print "Hello World".

(See the README.md file in the upper level 'examples' directory for more information about examples.)

## Example folder contents

ESP-IDF projects are built using CMake. The project build configuration is contained in `CMakeLists.txt` files that provide set of directives and instructions describing the project's source files and targets (executable, library, or both).

## Troubleshooting

* Program upload failure

    * Hardware connection is not correct: run `idf.py -p PORT monitor`, and reboot your board to see if there are any output logs.
    * The baud rate for downloading is too high: lower your baud rate in the `menuconfig` menu, and try again.
